Below is a list of WinMix Desktop keyboard shortcut. Note that this is not a complete list.

Shortcut Command
f1 Help
F4 Display the About dialog box
Alt+F4 Exits the program
Applications key Brings up a context menu of commands for the current playlist
DELETE Remove selected item from the play queue
TAB Cycles forward through controls on main window
Shift+TAB Cycles backward through controls on main window
Ctrl+c Copies the selected play queue item to the clipboard
Ctrl+D Moves selected item down in the play queue
Ctrl+U Moves selected item up in play queue
Ctrl+S Saves the current playlist
Ctrl+N Create a new playlist
Ctrl+O Pick audio files to add to current play queue
Ctrl+Shift+O Pick and load an existing playlist
Alt+P Begins playing the currently loaded item
Alt+U Pauses playback of currently playing item (use Alt+P to resume playback)
Alt+S Stops playback of currently playing item
Alt + N Moves to next item in the play queue
Alt + F Fast forwards through currently playing item
Ctrl + V Moves back to previous item
Ctrl+Shift+D Slows down the currently playing audio
Ctrl+Shift+S Speeds up currently playing audio
